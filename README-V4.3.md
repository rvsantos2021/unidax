# UNIDAX V4.3

Base Next.js App Router + TypeScript com páginas SEO orientadas a intenção comercial, FAQ estruturado e CTAs contextuais.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Verificações

```bash
npm run typecheck
npm run lint
npm run build
```

Veja `V4.3-PRODUCTION.md` para rotas, decisões e checklist de publicação. Variáveis de ambiente estão documentadas em `.env.example`.
